# 🌟 The Legends of Aetheria

A 2D action‑platformer fantasy adventure series following Kai, a young swordsman chosen by the elemental Aether Crystals.

This repository contains:
- Full game design documents
- Story and lore
- Character profiles
- Level structure
- Gameplay systems
- Starter code templates (Unity, Godot, engine‑agnostic)
- Assets and tools for development

---

## 🎮 Games in the Series

1. **Game 1 — The Lost Crystal**
2. **Game 2 — The Sunken Kingdom**
3. **Game 3 — Flames of the Dragon**
4. **Game 4 — The Sky Kingdom**
5. **Game 5 — The Final Light**
6. **Game 6 — The Awakening**

Each game expands the world, mechanics, and story.

---

## 🧑‍🚀 Main Character — Kai

- Brave, curious, stubborn, compassionate  
- Sword combat + elemental crystal abilities  
- Movement: run, jump, dash, wall jump  
- Crystal powers: Earth Shield, Water Healing, Fireball, Glide, Aether Blade
